# Arquitectura del set — plantillas por duración

> **Reconstruido.** Plantillas de fases con curvas de BPM y mapas de energía para sets de 2h, 3h y 4h. Reemplaza con la versión original si la tienes.

## Principio rector

La energía es una **curva**, no una recta. Cada set sube progresivamente, mete 1–2 **dips intencionales** (las variaciones) para que el oído descanse, y desde ahí pega más duro. La variación es el reset que hace que el siguiente peak pegue el doble.

Energía (escala 1–10) a lo largo del tiempo:

```
10 |                      ___                 _______
 8 |             ___     /   \         ______/       \
 6 |        ____/   \___/     \____   /                \
 4 |   ____/                       \_/                  \___
 2 |__/                                                     \__
   warm-up   build   peak1   VARIACIÓN   hard/rave        cierre
```

## Set de 2 horas (120 min)

| Fase | Minutos | % | BPM | Energía |
|------|---------|---|-----|---------|
| Warm-up | 0–18 | 15% | 120–124 | 4 → 5 |
| Build | 18–42 | 20% | 124–128 | 5 → 7 |
| Primer peak | 42–66 | 20% | 128–132 | 7 → 8 |
| Variación | 66–78 | 10% | 126–130 | 8 → 6 |
| Hard / rave | 78–102 | 20% | 132–144 | 7 → 10 |
| Cierre | 102–120 | 15% | 126–130 | 8 → 5 |

|------|---------|---|-----|---------|

| Build | 27–63 | 20% | 124–128 | 5 → 7 |

Para sets largos (3–4h) puedes meter **dos variaciones** (una tras el primer peak, otra a mitad del bloque duro) para sostener la atención.

## Carácter por fase

- **Warm-up:** groove hipnótico, no enseñes las cartas. Entras suave, construyes ambiente.
- **Build:** rodante, driving, el cuerpo empieza a engancharse. Sube ~1 BPM por track.
- **Primer peak:** euforia, hooks, manos arriba. El primer clímax.
- **Variación:** bajas un punto a propósito — melódico, breakdown, o un momento de color (EBM/acid). El reset.
- **Hard / rave:** lo más alto y duro. Kicks pesados, rave stabs, acid. Aquí se revienta.
- **Cierre:** bajas con intención. Un último golpe o una despedida hipnótica. Aterrizaje, no caída.
