# Paleta personal — el ADN del usuario

> **Reconstruido.** Este archivo captura el gusto firma del usuario para que cada set suene a él y no a un set genérico. Si tienes la versión original, reemplázala aquí. Actualízalo cada vez que el historial reciente revele algo nuevo.

El usuario tiene **dos polos** que conviven en su gusto. Un buen set los usa a ambos: SATIVA para el groove y la base, LOQUERA para el filo y el peak.

## Polo SATIVA — groovy, rodante, soleado

El lado tech house / house moderno. Groove redondo, bajos saltarines, vocal chops, energía de festival de día.

- **Carácter:** driving pero accesible, bouncy, hipnótico-luminoso.
- **BPM:** 122–128.
- **Artistas ancla:** Mau P, FISHER, Chris Lake, Chris Lorenzo, Cloonee, John Summit, Dom Dolla.
- **Dónde va en el set:** warm-up, build y primer peak. Es la columna del arranque.

## Polo LOQUERA — oscuro, duro, psicodélico

El lado hard techno / acid / rave / EBM. Filo industrial, stabs ácidos, post-punk, kicks pesados.

- **Carácter:** oscuro, tribal, hipnótico-agresivo, trippy.
- **BPM:** 132–148.
- **Artistas ancla:** I Hate Models, Nico Moreno, Sara Landry, Indira Paganotto, 999999999, Charlie Sparks, SEXTILE (color EBM/post-punk).
- **Dónde va en el set:** peak duro, rave, y como filo en las variaciones.

## Mapeo a las fases del set

| Fase | Polo dominante | Cómo suena en este usuario |
|------|----------------|----------------------------|
| Warm-up | SATIVA | Tech house groovy de Mau P / FISHER, entrada suave |
| Build | SATIVA → puente | Tech house rodante subiendo a techno hipnótico |
| Primer peak | SATIVA + filo | Peak time con hooks, empieza a oscurecer |
| Variación | LOQUERA (color) | Breakdown melódico o momento SEXTILE/EBM que suelta el oído |
| Hard peak / rave | LOQUERA | Hard techno + acid, lo más duro (I Hate Models, Nico Moreno) |
| Cierre | SATIVA | Vuelve al groove hipnótico, aterrizaje suave |

## Reglas firma

- Siempre cruza con el **historial reciente** (`Spotify:search` "mis más reproducidas de la última semana") antes de diseñar — el momento manda sobre esta plantilla.
- El **filo oscuro post-punk/EBM (SEXTILE)** es la firma del usuario en las variaciones: úsalo como color, no como base.
- Nunca un muro plano de kicks: este usuario valora la **curva** y las **transiciones**.
