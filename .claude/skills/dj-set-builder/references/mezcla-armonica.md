## La rueda de Camelot

Cada key tiene un código: número (1–12) + letra (**A** = menor, **B** = mayor). Tracks compatibles para mezclar:

1. **Misma key** (ej. 8A → 8A) — blend perfecto, invisible.
2. **±1 en la rueda, misma letra** (8A → 7A o 9A) — sube/baja energía suave manteniendo el mood.
3. **Mismo número, cambia letra** (8A → 8B) — cambia de menor a mayor (relativa), levanta el ánimo.
4. **+7 / "energy boost"** (8A → 3A) — salto de +1 semitono, sube energía notable (úsalo en builds).

Regla práctica: para **subir energía** sin romper el flow, +1 paso en la rueda (mismo letra) o pasa a la mayor relativa. Los saltos grandes de key van en los **breakdowns**, donde no hay tonalidad chocando.

## Reglas de BPM

- **Tracks vecinos: ±3–4 BPM.** Permite blends largos y limpios de 16–32 compases.
- **Saltos grandes de BPM → en los cambios de fase**, no dentro de una fase. Usa un breakdown o un track-puente para absorber el salto.
- **Sube gradual:** ~1 BPM por track en los builds. Bajar de golpe solo en la variación o el cierre, con intención.
- **Truco half/double-time:** un track a 140 puede mezclar con la sensación de 70 — útil para puentear entre tech house (~127) y hard techno (~140) sin que se sienta brusco.

## Técnicas de transición

- **EQ blend:** baja los graves del track saliente mientras subes los del entrante. Nunca dos kicks peleando. La transición base.
- **Puente por breakdown:** entra el track nuevo durante el breakdown del que sale (sin kick), y dejas que el drop del nuevo sea el momento. Ideal para cambiar de fase o de dureza.
- **Double drop:** alinea los drops de dos tracks compatibles para un golpe doble. Alto riesgo, alto impacto — guárdalo para el peak.
- **Loop roll / filtro:** loopea 1–4 compases del saliente y aplica un filtro high-pass para crear tensión antes de soltar el entrante.

## Cómo encaja con el set

- **Warm-up → build:** mismo key o ±1, BPM contiguo. Transiciones invisibles.
- **Build → peak:** energy boost (+7 en la rueda) o paso a mayor para levantar.
- **Peak → variación:** puente por breakdown; aquí puedes hacer el salto de key/BPM más grande.
- **Variación → hard/rave:** desde el reset, entra duro con un double drop o un drop limpio en breakdown.
- **Rave → cierre:** baja BPM gradual y vuelve a keys menores hipnóticas para el aterrizaje.
